## 本地包元数据

- 别名/备注：`state.db.user_mod_data(mod_id, alias, notes)`；本地 `mod_id = local:data:<sha256(规范化包路径)[:18]>`，改名换路径会产生新 ID。
- 本地包名称和说明依赖 `alias + notes`；`description` 只来自工坊缓存。统一通过 `tools/build_pack.py --deploy` 写入，禁止手工复制后漏写。
- 封面：pack 同目录同名 `.png/.jpg/.jpeg/.webp`；本地包通常为 `data\<stem>.png`。`!!!!wyccc_runtime_options.pack` 是隐藏内部包，无需元数据。
- 本地包若与工坊目录内同名 pack 冲突，可能继承工坊标题、简介和封面；排查显示异常时检查 `workshop_cache.json` 与 `workshop_pack_index.json`。

  - `subscribe_workshop_items(ids, root=...)`
  - `perform_workshop_operation('subscribe'|'unsubscribe'|'force_update', id, root=...)`
