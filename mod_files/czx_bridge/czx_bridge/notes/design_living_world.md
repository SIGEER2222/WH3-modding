# Living World —— 以"生动"为目标的 WH3 设计

> 2026-09-16。定位修正：本 MOD 的首要目标是**让游戏更生动**——世界有声音、角色有人味、事件有戏剧感；回合战斗只是触发面之一。
> RimTalk 在 RimWorld 里成功靠的是"小人会聊天"；WH3 的等价物不是单位闲聊，而是**传奇领主、派系嗓音、宏大叙事**——这是 TW 自己的素材富矿。

---

## 1. WH3 独有的"生动素材"盘点（RimWorld 没有的优势）

| 素材 | 为什么是好燃料 |
|---|---|
| **传奇领主固定集合**（~100 位，有官方 lore） | 人设库可以**精修且限量**——Karl Franz、Malekith、Skarbrand、Kairos 各有人格原型，一次写好长期受益，不像随机小人是无限长尾 |
| **派系嗓音极强** | 鼠人 yes-yes 语癖、矮人"仇恨之书记下了"、恐虐血祭、奸奇谜语、纳垢腐烂慈爱、色孽放纵、蜥蜴人古圣大计划、震旦阴阳和谐——每族有现成腔调 |
| **机制即叙事钩子** | 矮人仇恨清单、绿皮 Waaagh、震旦阴阳、混沌裂缝、纳垢瘟疫、色孽诱惑——游戏机制本身就是剧情发生器 |
| **领主间已知恩怨** | Malekith↔Tyrion/Teclis、Karl Franz↔Vlad、恐虐↔色孽——对话可以有真实的"关系历史" |
| **战役大事件流** | 宣战/合邦/围城墙破/裂缝开启/仪式完成/任务发布——现成叙事节拍 |
| **战场戏剧时刻** | 领主单挑、巨兽狂暴、溃逃、增援入场、占领点易手——战斗自带高潮 |
| **世界观地名/地标** | 阿尔道夫、狮鹫林、巍京——叙事有地名锚点 |

## 2. Persona 系统（生动的人格层）

### 2.1 三层人设

```text
L1 传奇领主：精修人设（限量 ~100，可打包发布）
   Karl Franz: 帝国政治家，威严务实，关心选帝侯与帝国存续
   Malekith:   千年怨念，冰冷傲慢，对凤凰王位的执念
   Skarbrand:  狂怒化身，句式短促，三句不离血与颅骨
   Kairos:     双头织命者，一口说过去一口说未来
   Skarsnik:   奸诈地精军阀，night goblin 式阴阳怪气
   ...

L2 派系嗓音包：文化级 fallback（~24 个派系）
   Skaven 啮齿语癖 / Dwarf 账本腔 / Cathay 朝堂雅言 / Norsca 蛮族咆哮...

L3 通用职业模板：英雄/事务官/无名领主
   战斗法师/猎巫人/贵族/族长 —— 按职业+文化合成
```

- 人设是**文本资产不是代码**：persona 文件包，社区可共创/翻译（RimTalk 的提示词包生态已验证这条路）
- 每场战役只激活当前存在的领主人设——动态装配

### 2.2 上下文绑定：让领主"知道自己在哪"

台词质量取决于喂给 LLM 的上下文。按 RimTalk Context Filter 思路分档：

```text
Essential:  领主名/派系/当前事件/地点
Standard:   +军队构成/健康状态/与相关派系的关系/最近战绩/正在进行的目标
Full:       +仇恨清单/Waaagh 状态/混沌腐蚀等级/盟友关系/特性/装备/季节/行省环境
```

## 3. 叙事触发面（"什么时候该有声音"）

### 3.1 战役层触发点（主舞台）

| 事件 | 叙事输出示例 |
|---|---|
| 宣战 | 宣战方领主用其人设宣战："卡拉兹-阿-卡拉克记下了这笔账，鼠辈"（矮人） |
| 议和/背盟 | 被拒/被背刺的当事人视角反应 |
| 领主负伤/阵亡 | 讣告/重伤独白/阵营反应 |
| 攻下/失守城池 | 守将遗言/胜利宣言/屠城或占领的派系风格描述 |
| 混沌裂缝开启 | 全图广播式的恐惧氛围文 |
| 仪式/祭礼完成 | 施法方胜利独白 |
| 英雄行动成败 | 事务官的得意/狼狈自白 |
| 合邦/附庸 | 被合邦派系的最后独白 |
| 你的领主升级/新特性/重伤复原 | 领主的私人独白（"主角感"） |
| 回合结束 | "与此同时在世界彼端…"远处大事一句话转播（战史感） |
| 大胜利/大胜回合 | 编年史段落追加 |

### 3.2 战斗层触发点

| 事件 | 输出 |
|---|---|
| 开战部署完成 | 双方领主阵前喊话（阵营+仇恨关系定制） |
| 领主接战/单挑 | 仇敌相见分外眼红型台词 |
| 敌方领主溃逃/阵亡 | 胜者嘲讽 / 己方哀悼 |
| 巨兽狂暴/召唤物入场 | 解说员惊叹 |
| 炮兵齐射/法术大场面 | 战场解说节拍 |
| 溃逃潮 | 幸存者恐慌 barks |
| 胜负判定 | 战后评词（胜方风格化、败方悲壮化） |
| 占领点易手（攻城/统治战） | 攻防双方反应 |

### 3.3 环境/氛围触发（idle 也有生命）

- 长时间无战事的回合：领主们谈远征、谈天气、谈补给——低优先级后台触发，冷却很长
- 行军过境特殊地标（帝国军队路过狮鹫林）：一句即景
- 长时间围城：守方日记式独白

## 4. 旗舰场景："与传奇领主对话"（外交拟人化）

WH3 版 RimTalk 的灵魂功能：**外交/事件界面里，传奇领主用人设说话，玩家能接话**。

### 4.1 实现路径（UI 受限下的可行方案）

WH3 campaign UI 没有自由文本输入框 `[需验证]`——"玩家打字问 Malekith"做不到。降级为**选项树对话**：

```text
事件/外交触发 → 弹出 dilemma 窗口：
   Malekith 的开场白（LLM 生成，带人设）
   [选项1] "纳加隆德欠血债，偿还是讲和？"
   [选项2] "奥苏安迟早是我帝国的盟友"
   [选项3] "闭嘴，开战吧"
玩家点选 → 领主按人设回应 → 可能接 2-3 层
```

- dilemma UI 是脚本可控的原生通路（mod 圈有大量 dilemma mod）→ **可行性最高**
- 选项可由 LLM 生成（按当前外交状态出 3-4 个符合玩家立场的选项）——"选项式对话"反而比自由输入更适合手柄式游戏
- 每回合限频，关键时刻才弹（外交提议/被宣战/被求援）

### 4.2 延伸：事务官汇报体

你的英雄/事务官在地图上干活 → 成功/失败时弹"汇报"——人设化的战报，把干巴巴的 "+250 经验" 变成 "猎巫人回报：异端已净化，村庄欠你一次"。

## 5. 战斗层生动化（与 czx 的分工）

| 内容 | 谁做 |
|---|---|
| 战术决策/移动/攻击 | czx（纯 Lua，无 LLM） |
| 战况解说/领主台词/戏剧时刻文本 | bridge daemon（LLM 或模板兜底） |

- 战斗文本必须**低延迟红线**：高频时刻用本地模板兜底，LLM 只接低频大事件（开战喊话/领主阵亡/胜负），冷却硬约束
- 解说开关独立于台词开关：有人要"体育解说"，有人要"角色扮演"，MCT 分开

## 6. UI 注入通路盘点 `[需验证]`

| 通路 | 场景 | 可行性 |
|---|---|---|
| dilemma/事件弹窗 | campaign 对话/提案/播报 | ✅ 最成熟（原生脚本通路） |
| event feed 消息流 | campaign 一行式播报 | ✅ |
| advisor 顾问消息 | campaign+battle | ⚠️ battle 侧 Infotext Manager 存在 |
| floating text / text pointer | battle 头顶文 | ⚠️ Text Pointers 接口存在，能指到单位 |
| 自定义 UI 面板 | 对话窗 | ⚠️ WH3 UI 自定义成本高，最后用 |

## 7. 体验护栏（防翻车）

| 护栏 | 做法 |
|---|---|
| 刷屏 | 每类事件独立冷却 + 全局 token 预算 + "本回合最多 N 条" |
| 人设跑偏 | persona 文件里写死口吻规则 + few-shot 示例；生成后做禁用词过滤 |
| 剧透/作弊感 | 只喂"玩家可见"信息；不可见敌军不进上下文（is_visible_to_alliance） |
| LLM 断线 | 模板兜底文案无缝接管；daemon 离线 = 静默关闭，原版体验不变 |
| 重复感 | 事件记忆：同类事件冷却随次数递增；daemon 侧去重 |

## 8. 交付切片建议

```text
Slice 1  "会说话的战役"：3 个事件（宣战/城池易手/领主阵亡）
          × dilemma/event feed 注入 × 模板文案（无 LLM 也成立）
Slice 2  接 LLM：persona 系统 + 领主人设库（先做 10 个传奇领主）
Slice 3  外交对话树（选项式）
Slice 4  战斗层文本（开战喊话/领主阵亡/胜负评词）
Slice 5  事务官汇报/编年史/ambient
———
每个 slice 独立可用；LLM 层整体可拆，模板兜底保证 mod 永不白装
```

**一句话**：RimTalk 让 RimWorld 的小人会聊天；WH3 版要让**传奇领主、派系、整个旧世界会说话**——人设有 lore 地基，事件有机制钩子，缺的只是把它们接起来的一根管子。
