# WH3 世界观参考（Living World persona 素材库）

> 用途：给 persona 模板/解说文案/对话树提供 lore 地基。来源：TW:WH3 官方派系设定 + Warhammer Fantasy 社区 lore（Lexicanum/Fandom/Warhammer Community）。
> 规模基线：Immortal Empires ~24 种族 / ~96 派系 / 105 位传奇领主（Update 8.0）。

---

## 1. 世界观底色（写文案时的基调）

- **Warhammer Fantasy = 旧世界（World-that-Was）**：哥特+文艺复兴式的压抑奇幻，绝望与荒诞并存，黑暗幽默是官方底色（鼠人的滑稽阴险、绿皮的混不吝、矮人的记账式仇恨都是半喜剧半恐怖）。
- **WH3 主轴**：混沌魔域/不朽帝国。北有混沌荒原四神，南有文明秩序；震旦守长城（Great Bastion）抗混沌，基斯里夫是混沌与文明的前线。
- **"没有人是干净的"**：秩序方也各有原罪（帝国猎巫、巴托骑士踩农奴、暗精奴隶制）——写台词别写成纯善纯恶。

## 7. 写作红线

- 反派可以坏但**不要现代腔/网络梗**——全战世界观是严肃奇幻+黑色幽默
- 台词长度：bark ≤ 2 句，解说 ≤ 3 句，对话树回合 ≤ 4 句
- 人设一致性 > 文采：Skarbrand 永远只说杀戮相关，不许抒情
- 只有 lore 明确的才写进人设卡；其余走派系通用模板，不发明官方没有的设定
